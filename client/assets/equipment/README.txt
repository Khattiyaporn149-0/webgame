Place your equipment sprites here, organized by slot.

Slots (subfolders):
- hat
- mask
- suit
- back
- acc

File format:
- PNG with transparent background
- Recommended size: match your base character sprite size
- Naming: <name>.png (e.g., golden_hat.png)

Paths used by lobby overlay:
../assets/equipment/<slot>/<name>.png

Example (you add these later):
client/assets/equipment/hat/space_helmet.png
client/assets/equipment/suit/black_ops.png
client/assets/equipment/acc/monocle.png

Selections are saved to localStorage key: ggd.equip
